# 单节点部署、服务边界与恢复

[文档总目录](../README.md)

> 规格版本：2.6.0；状态：待实现的规范性设计。MUST/必须表示实现及验收要求，不能理解为现有功能。

## 宿主目录

| 路径 | 拥有者/用途 | 插件可见性 |
|---|---|---|
| /etc/xelab | 内核配置、TLS、密钥路径 | 默认不可见 |
| /run/xelab/control.sock | 内核及授权宿主管理员组；0660 | 不挂载给插件 |
| /var/lib/xelab/metadata | PostgreSQL 数据或其独立受保护目录 | 不可见 |
| /var/lib/xelab/volumes | 平台管理业务卷与硬配额 | 只挂明确批准子卷 |
| /var/lib/xelab/blobs | 不可变受控对象 | 通过 HostService 访问 |
| /var/lib/xelab/tmp | 临时下载/上传/恢复区 | 有全局和操作级容量上限 |

OS、数据库、containerd 和日志基础设施计入 system_reserved。内核由宿主服务管理，插件通过内核控制；插件不能重启/修改内核服务配置。

## 网络与浏览器来源

public_origin 是可信认证来源；不可信 WebUI 使用其他注册 origin 或受控 sandbox。同一主机可绑定不同域名，但域名共用 IP 不意味着浏览器同源。TLS 校验默认开启，生产不使用跳过证书验证开关。

本版不默认信任外部 X-Forwarded-*，实际 peer 来自接入 socket。若未来引入反向代理，需显式可信代理列表及完整来源校验契约；不能直接相信任意调用者传入的真实 IP。

## 宿主重启

启动控制面及必要基础设施，执行全量对账，管理面就绪后恢复插件。发现无法核实的任务外部结果进入 unknown，不因“重启恢复”而自动重放。

同机多副本只能隔离进程崩溃，不隔离宿主断电、内核漏洞和磁盘损坏。重要备份放宿主之外；恢复期间平台可能停机，当前没有跨节点 failover 接口。
