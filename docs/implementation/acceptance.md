## 接口结构验收

所有 operationId 唯一；所有路径参数定义；请求/响应 Schema 无悬空引用；参数与状态码匹配逐接口文档；所有示例按 Schema 校验。Proto 必须编译，服务方法与逐 RPC 文档一一对应，SQL 必须能解析；真实数据库约束另做集成验收。

## 安全与继承

| 编号 | 触发 | 期望 |
|---|---|---|
| AUTH-01 | Guest 调用平台运维接口 | 403；自助子账户/Key 创建仍在范围/额度内可用 |
| AUTH-02 | 子账户另绑高权限组 | 仍受父级/固定上限约束，不能越权 |
| AUTH-03 | all_snapshot 后父级新增动作 | 下级不增加；follow_parent 明确增加 |
| AUTH-04 | 父级收权/禁用 | 新调用、重试和后续步骤停止授权 |
| AUTH-05 | K1 签发 K2，随后吊销 K1 | K2 链失效，其他独立 Key 不受影响 |
| AUTH-06 | 相同签发幂等键重试 | 不重复签发、不恢复明文，409 可核实资源引用 |
| AUTH-07 | 猜测其他用户资源 ID | 404/403，无数据泄漏 |
| AUTH-08 | 最后独立 Owner 被禁用 | 409，保留可恢复根 |
| AUTH-09 | 并发创建超过树配额 | 最多额度内成功，不超售 |

## 生命周期与资源

| 编号 | 注入点 | 期望 |
|---|---|---|
| RUN-01 | DB 提交后、OCI 创建前崩溃 | 重启同实例 ID 继续，无重复预留 |
| RUN-02 | OCI 已创建、观测未提交崩溃 | 通过标签找回，不留孤儿运行 |
| RUN-03 | 插件满 CPU/内存 | 父级合计限制有效，内核保留至少 4C16G，管理动作可执行 |
| RUN-04 | 可写卷写满/尝试越界挂载 | 只影响授权卷，平台拒绝未经授权访问 |
| RUN-05 | 新旧并行升级资源不足 | 等待/拒绝，不借用内核预留 |
| RUN-06 | 迁移后旧版不兼容 | 拒绝仅切镜像回退，使用核实备份流程 |
| RUN-07 | WebUI 卸载或失败 | 内核和 CLI 独立可用，用户/授权记录保留 |

## 任务与通信

TASK-01：发送成功但结果回写前崩溃，进入 unknown，不能自动重发。

TASK-02：旧租约迟到结果被 fence 拒绝；接管不能假定已阻止外部副作用。

STREAM-01：慢消费者受有界缓存和超时限制；断开向全部下游传播取消。

EVENT-01：确认前断线会重投；旧 lease 不推进新游标；死信可核查。

BACKUP-01：从宿主外备份和独立密钥恢复，验证元数据、卷、源链撤销水位；宿主故障期间不宣称持续可用。
