# M2 离线元数据库快照与恢复身份隔离

本页说明全平台离线恢复的元数据组件、启动门禁和恢复身份隔离。
备份/恢复 CLI 及 Blob/镜像/卷整体重建已接通，见[整体恢复实现与证据](m2-platform-restores.md)；
正式 AWS/独立宿主恢复验收与完整 DataMigration 仍未完成。

## 数据格式与边界

元数据库采用原生 PostgreSQL COPY 数据流，不执行输入中的 SQL、DDL、表名或约束。表集合来自代码内迁移，列布局与当前可信目标逐列核对；只支持相同 PostgreSQL 主版本和精确的内部迁移版本/校验和。跨版本升级另行交付。

源导出使用同一 `REPEATABLE READ READ ONLY` 事务，保存观察到的 WAL 位置和永不回收的 project ID 高水位。它不是连续 WAL 归档或时间点恢复。整个元数据流最多 1 GiB、合计一千万行，单行展开后的 JSON 表示最多 8 MiB；先检查展开大小，避免把压缩或 TOAST 大字段误当成小记录。帧最多 64 KiB，头部最多 256 KiB，公开组件调用限时五分钟。

迁移历史、目标恢复门禁及旧恢复 Owner 锚点不进入快照。逐表摘要、行数、完整尾部和全流摘要必须匹配外层已认证清单。组件输出本身是明文，整体离线协调器持有宿主与数据库租约、停止和隔离所有写者，使用受保护的暂存或管道接入加密传输。

## 空库导入与门禁

先使用当前代码建立可信空库及持久的 `importing` 恢复记录，随后导入数据。目标的表结构、迁移历史及门禁不会被快照覆盖。导入在一个事务中临时移除目标自身的外键，流入全部数据，再重建并验证这些可信外键；无需 PostgreSQL 超级用户或关闭触发器。元数据、约束验证和权限重置在同一事务提交，截断、摘要不符、断裂引用或密码不合要求均回滚。序列只向前推进，允许失败时留下间隙。

导入成功只进入 `rebuilding`，并记录已验证的元数据摘要。`importing` 和 `rebuilding` 都使 `Db::check` 拒绝启动。元数据组件不把门禁改成 `ready`；由整体恢复协调器完成实际文件系统、镜像及权限验证后原子放行。进程退出或更换配置目录不能移除数据库中的门禁。

恢复门禁及恢复 Owner 权限来源首次在内部版本 **9** 引入。后续内部迁移继续保留已发布 SQL 和校验和；停机迁移目标必须与所使用可信二进制的 `SCHEMA_VERSION` 一致。旧二进制拒绝较新布局，不能直接回退。

## 旧权限不能随快照复活

恢复必须选择快照中一个未归档的独立根用户作为恢复 Owner，并设置与其快照密码不同的新密码。保留账户 UUID、创建时间、资源归属与树结构；所有旧凭证和 Grant 撤销，所有账户的旧密码与激活材料清除，其余账户禁用，已归档账户继续归档。即使之后重新启用子账户，旧密码仍然无效。

继承上限清空，旧签发凭证和旧权限来源记录移除。权限定义及内置角色从当前代码重建，撤销旧 OAuth/执行委托、Secret 与绑定，租约立即到期，发布者信任撤销。部署禁用、实例停止、旧挂载和批准移除、卷 fence 前进，未完成调用置为结果未知，未完成操作/备份任务失败，释放旧资源预留，保留历史每日用量。重新授权、密钥重建与发布者复核都需要当前有效权限和明确的新操作。

恢复 Owner 获得新建的 Owner Grant 与明确的宿主恢复锚点；新 Grant 使用当前真实时间，不伪造原引导时间。普通 API 不能写入这些锚点。缺少该独立来源的自授 Grant 不能互相证明权限。

## 显式重新信任已有发布者

恢复 Owner 使用新会话核对保存的发布者 UUID、key_id 及公钥，通过 trustPublisher
提交原名称、key_id 和已复核的 Ed25519 公钥。已有 key_id 的权限对象是已有 UUID，
创建新对象的权限不等于重新信任这个对象。密钥按解析后的 Ed25519 值比较，名称或
密钥不匹配则拒绝；更换密钥必须使用新的 key_id，不能悄悄改写旧安装的信任根。

已有身份返回 200，撤销状态改为 trusted 时只增加修订和当前更新时间，保留 UUID、
创建时间、原公钥文本及安装引用；新 key_id 创建身份返回 201。已可信的同一身份
是无修改确认。信任与撤销共享授权围栏，幂等重放也检查原调用所需的当前权限。
重新信任不启用部署，不复活旧会话、Grant、代理批准或 Secret 绑定，仍需分别复核。

## 当前验证

真实 PostgreSQL 测试覆盖旧令牌/密码拒绝、子账户重启用、归档状态、每日配额保留、新 Owner 授权、锚点缺失时拒绝授权、元数据往返、序列高水位、尾部损坏、摘要不符、截断、非法表/列/版本、大帧、展开大字段及外键校验失败的完整回滚。

上述是元数据组件证据，不是文件系统、真实 AWS 或独立宿主灾难恢复通过证据。原有 OCI、XFS、MinIO、身份与控制器回归仍以最终提交的 CI 实际结果为准。
