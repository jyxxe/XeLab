# API Key 签发、轮换与吊销

[文档总目录](../README.md)

> 规格版本：2.6.0；状态：待实现的规范性设计。MUST/必须表示实现及验收要求，不能理解为现有功能。

## 签发

CreateApiKey 必须明确继承 mode、conditions.expires_at。最大有效期 365 天且不得超过源凭证链期限。密钥至少 256 bit CSPRNG 熵，带可辨识非敏感前缀，服务端存 HMAC 校验摘要而非可还原明文。

签发事务检查账户链、实际创建凭证范围、树配额，保存 Credential/InheritanceGrant/幂等元数据/审计；明文仅首次响应。响应失败后用元数据核实，无法恢复密钥时撤销并重新签发。

## 幂等与一次性响应

普通幂等重放不能再次展示密钥。相同请求键已成功签发但首次响应丢失时返回 409 ONE_TIME_RESPONSE_UNAVAILABLE，响应 details 不能携带明文；可通过 listApiKeys 查找前缀与创建时间。不能为了可重放把密钥加密后写进幂等表。

## 轮换

rotateApiKey 需要当前旧密钥 ETag。新上限不超过旧密钥当前有效范围和操作主体范围；事务内创建新凭证并撤销旧凭证。旧派生链同步失效，不自动迁移到新 Key。新的 Key 保留旧 Key 以外的原始委托约束，不能把被吊销旧 Key 设置为新 Key 的持续源而导致新 Key 立即失效。

## 吊销范围

- 吊销 K1：K1 和由它签发的受限委托链失效。
- 吊销其他独立 K2：不影响同账户其他独立凭证。
- 账户/祖先禁用：全部相关链暂时失效。
- 永久 revoked：父级恢复不能复活，必须重新签发。

Key 只作为 API 凭证，不用来直接建立不受来源链约束的普通浏览器会话。每次调用记录 credential_id，禁止把 Authorization 头记入日志。
