# 升级、迁移与回滚

[文档总目录](../README.md)

> 规格版本：2.6.0；状态：待实现的规范性设计。MUST/必须表示实现及验收要求，不能理解为现有功能。

## 两种升级策略

| 策略 | 前置条件 | 执行顺序 |
|---|---|---|
| recreate | 独占可写卷默认使用；allow_downtime=true | 撤路由→排空→停旧→卷写锁→备份→迁移→启新→验证→开路由 |
| parallel_compatible | 清单声明并验证并发访问/格式兼容，插件池可容纳新旧实例 | 预留新版→健康→原子切流→旧版排空→释放旧预留 |

新旧同时运行的 CPU/内存全部计入插件池；容量不足返回 RESOURCE_EXHAUSTED 或等待资源，不能借用内核 4C16G。single_writer 卷禁止 parallel_compatible 并发写。

## 迁移契约

DataMigration.Plan 生成计划摘要，描述独占写、向后读兼容、可逆性、临时容量。Apply 必须携带计划摘要、可用 backup_id 和当前 volume_fence。卷写锁在迁移前获取，新旧进程不能越过 fence 同时写入。

迁移不是初始化副作用：Describe/Initialize 不得偷偷修改已有数据格式。迁移结果必须持久化，崩溃后按计划 ID 查询/验证，不重新执行未确认副作用。

## 回滚条件

程序回退要求旧版读取当前数据格式；不兼容时返回 MIGRATION_INCOMPATIBLE，不能仅换镜像。需要恢复备份时先停写，将备份恢复到新卷并验证，再切换绑定；原卷保留到恢复验收结束。

长期任务保持原工作流/契约/提供者绑定。升级不兼容时暂停并显式安排恢复；不得把旧检查点直接交给无法识别该版本的新版。

验收注入点：迁移前失败、迁移中掉电、切流后探针失败、回滚旧版无法读格式、备份不可用。每种情况都必须明确当前可写卷及可服务版本。
