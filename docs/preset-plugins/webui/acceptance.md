# WebUI与batch验收

[WebUI目录](README.md) · [Skill验收](../../skills/acceptance.md)

> 规格版本：2.6.0；以下是待实现验收条件，不代表已运行交互测试。

| 场景 | 必须成立 |
|---|---|
| 无WebUI/停用WebUI | 核心管理API、CLI与已接受batch继续可用；内核预留不被借走 |
| 主题切换 | system随浏览器偏好；light/dark/custom即时生效；保存/重登恢复；不重发业务 |
| 减少动画/透明度 | 实色/减少动画仍可完成全部操作；错误和焦点不只依赖颜色 |
| 窗口操作 | 打开、聚焦、拖动、缩放、最小化、最大化/恢复、关闭；小屏控制按钮可达 |
| 可选贡献 | 仅window、仅widget、两者及无UI插件均能安装；无UI不阻断业务 |
| 组件布局 | 多实例布局、尺寸约束、活动上限、隐藏停刷、重新可见只刷新一次 |
| 跨源隔离 | 插件不能读壳DOM/令牌，不能覆盖菜单或可信授权页，不能导航顶层 |
| 桥伪造 | 错origin/source/nonce/view_id/版本、重复seq、未声明方法/Skill均拒绝 |
| 桥副作用 | 超时不换键重放；同键同请求去重，同键异内容冲突；隐藏组件不周期提交batch |
| 版本/权限变化 | 停用/升级/撤权立即阻止新请求；旧frame不继承新白名单 |
| 异步接收 | batch在持久化后返回202；重启后仍可查，无浏览器在线依赖 |
| 逐项结果 | 顺序关联不变；成功/失败/取消/unknown分别展示；跨item不虚报原子性 |
| 取消与重启 | 关闭窗口不取消；显式取消保留已提交项；旧fence不得覆盖结果 |
| 账户隔离 | Guest只见明确共享贡献；切换账户清空桥/私有状态；子账户不自动读父结果 |
| 结果保留 | 到期410、引用Blob遵守自身TTL、GC不暴露私有对象路径 |

文档工具可校验Schema、样例、接口及权限绑定；真实浏览器隔离、组件可用性、资源峰值、重启与故障恢复必须在实现后单独验收。当前建议0.5vCPU/512MiB不能当作已通过这些场景的证据。
