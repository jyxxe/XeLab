# 内置管理应用与业务入口

[WebUI目录](README.md)

> 规格版本：2.6.0；状态：待实现的规范。

内置管理应用由WebUI维护，调用已有核心API；第三方贡献只能通过声明的桥接Skill执行，不开放通用管理HTTP代理给iframe。

| 应用 | 必须展示与操作 |
|---|---|
| 插件中心 | 安装/审批/部署/启停/升级状态、资源预算、依赖、UI贡献；建议值与实测值区分 |
| Skill浏览器 | 固定UUID、版本/摘要、目标插件/契约、可用性、输入表单、同步单次测试和异步batch |
| 任务中心 | 工作流、批次、定时计划分清对象类型；查询、逐项结果、授权暂停、取消 |
| 知识库 | 数据表/字段/行、类型校验、表达式参数、媒体引用、按字段向量开关及默认128维 |
| 账户与权限 | Owner/Operator/Member/Auditor/Guest、组来源、父子账户树、API Key和固定继承模式 |
| 设置 | 主题、减少动画/透明度、Dock/组件布局、连接信息、当前默认UI |

知识库向量配置选择精确embedding Skill，展示模型/空间/维度/代次和pending/failed。未安装embedding时普通表与标量查询继续可用，向量查询/构建显示依赖不可用原因。

知识表交互式rows-query使用同步调用返回完整ids/count，再由rows-get按明确ID分段读取正文；CSV等批量输入（若该UI实现支持该文件格式）解析为受Schema约束的upsert项目后异步提交。每个item内部最多64行；partial结果逐项呈现，不让用户误以为整份导入原子提交。

表达式编辑器以a.match(...).topk(...).match(...)展示链和当前完整ID数量，保留顺序、不移动后置过滤或补足k。需显示len等标量函数、topk阶段和参数类型；require_complete_index默认true，用户显式选择部分索引结果时展示候选覆盖范围，不静默忽略未索引数据。

密钥仅首次明文展示，平台密码输入在可信登录页。所有界面动作由当前授权驱动，按钮可见性不是权限证明；遇到401/403停止请求并显示当前有效来源/限制，不能切到WebUI后台服务权限重试。

WebUI管理员不能通过“打开插件页面”取得表数据访问权。Guest可看到明确共享界面和自己的非敏感偏好；未授权菜单和结果不泄露其他账户对象。

查询详情可显示本请求缓存状态与向量stage_index/index_revision；全局缓存容量由有部署配置权的用户通过现有updateDeployment管理，不向普通查询用户授予改插件预算的权限。读取行正文需要时传原schema/data水位，失配重新查询，不展示混合快照。

微插件管理独立列出身份/版本/源码摘要/运行绑定/父MPR状态，创建微部署后显示candidate_skill并按权限注册/启用。界面区分普通容器部署与微部署，不把“运行脚本”显示成上传任意代码到管理API；微源码与调用诊断分别授权，JSON输出按文本/数据渲染。

网页搜索界面只展示query/limit、服务商顺序和授权后的绑定管理，密钥通过核心Secret输入，不作为脚本参数。对象存储界面按当前用户列文件、查看元数据、上传Blob导入/导出下载；不能用用户可编辑owner/path字段切换命名空间，批量文件处理走异步batch。
