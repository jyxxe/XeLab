# 插件桌面组件

[WebUI目录](README.md) · [贡献字段](../../api/models/UiWidgetSize.md)

> 规格版本：2.6.0；状态：待实现的规范。

桌面组件为kind=widget的独立iframe，复用窗口的跨源隔离、固定版本与消息桥。其定位、外框、移除/刷新/错误按钮由壳管理；不把插件HTML、脚本或CSS拼进桌面DOM。

网格每格96逻辑像素、间距12，坐标从0开始；columns/rows以及min/max都在1..8内。布局保存为UiWidgetPlacement，instance_id允许用户放置多个独立实例；调整大小遵守贡献约束并避免遮挡窗口控制区。视口变窄时顺序重排，不改写服务器保存的原布局。

默认没有自动添加的第三方组件；用户从可见贡献选择后加入本人桌面，默认最多8个活动iframe，保存布局最多32项。超出活动上限的组件显示待激活占位，不能偷偷挂载32个后台页面。

refresh_interval_seconds=0为手动刷新，否则30..3600秒，实际间隔取贡献声明和部署widget_min_refresh_seconds较大者。由宿主发widget.refresh事件，组件可用已批准只读Skill更新；失败按退避处理，禁止计时器持续提交变更批次。

自动刷新仅限目标side_effect=none的已批准读取，受当前用户额度；昂贵embedding或批次创建默认不属于周期刷新。需要业务写入/提交batch时必须是用户明确操作，并在贡献白名单中声明相应绑定/方式；宿主不把周期刷新事件当用户意图。

页面不可见、组件离开可见区域、会话失效、插件未就绪时停止宿主刷新并发送visibility=false；重新可见只刷新一次，再恢复周期。组件不得假设宿主能强制暂停恶意JS，资源压力时宿主直接卸载iframe。

推荐组件：只读索引pending/failed数、本人任务进度、插件健康摘要。知识库原始行和媒体预览仍要通过对应Skill权限；不能以“桌面摘要”为由绕过表owner/indexer ACL。

移除组件销毁消息通道并保存新布局，不删除插件数据，不取消已接受的batch。业务未就绪显示原因和最近更新时间，不能无限加载或伪造零错误。
