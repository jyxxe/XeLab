# 桌面壳与导航

[WebUI目录](README.md)

> 规格版本：2.8.0；状态：待实现的交互规范。

桌面分为固定顶部菜单栏、可用工作区、桌面组件层、窗口层、Dock、通知/对话框层。层级由壳统一管理，插件不能覆盖菜单栏、可信授权提示或系统关闭按钮。

| 区域 | 行为 |
|---|---|
| 顶部菜单栏 | 显示平台名、当前应用、连接/任务状态、主题切换和用户菜单；应用名为纯文本 |
| 桌面工作区 | 主题背景和组件网格，保留拖动空白；窗口最大化只占可用工作区 |
| Dock | 内置应用、用户固定窗口贡献、活动/最小化标记；支持底部/左/右和自动隐藏 |
| 应用启动器 | 按可见贡献搜索、启动；无UI插件仍可在插件/Skill管理中使用 |
| 通知中心 | 汇总本用户异步任务结果、失败、授权/依赖暂停；不显示别人的输入输出 |

首次进入展示桌面，内置应用包括插件中心、Skill浏览器、任务中心、知识库、账户与权限、设置。其入口可见性来自当前授权，但隐藏按钮不是服务端权限检查。

类似macOS的体验体现在简洁菜单、悬浮Dock、圆角窗口、可选半透明和一致的焦点反馈。图标/窗口操作要有文本提示，颜色不是唯一状态提示；减少动画/透明度时仍能完整使用。

默认单桌面，不把多桌面/原生宿主程序集成列为v1必需。桌面壳不访问宿主进程、文件系统或系统快捷键。

鼠标和键盘均可打开应用、切换窗口、最小化、关闭及调整大小；提供应用启动器按钮和窗口列表，不能仅依赖浏览器可能拦截的系统快捷键。焦点环、可读名称和逻辑Tab顺序为必需。

窄屏采用单活动窗口+可展开应用列表，组件转为顺序面板；保留任务状态和主题设置，避免强制横向滚动桌面。窗口位置在视口/缩放变化后夹回可用区域，控制按钮不能移到屏幕外。

顶层可信登录在独立认证页跳转，不在插件iframe中提示用户输入平台密码。会话失效时壳停止新请求、清空私有视图/桥上下文，再引导登录；后台批次按核心状态处理。
