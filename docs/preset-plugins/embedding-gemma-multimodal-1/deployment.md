# 资源、部署与验收

[文档总目录](../../README.md)

> 规格版本：2.8.0；状态：设计预设，尚未构建或实测运行。

默认 1 vCPU/6 GiB、临时盘1GiB、pids128、单副本；CPU和内存是平台批准限额，包含模型、张量、解码、队列与结果缓冲。模板先 disabled，替换真实installation_id并验证镜像/模型锁后启用。

默认镜像program只读，模型共享OCI层可减少磁盘重复，但不假设不同容器共享RAM。并行升级需要额外完整实例预算，资源不足采用明确的recreate窗口。

验收必须覆盖：固定并发边界、队列满/超时、混合用户、最长文本、最大媒体解码、取消释放槽、源码锁校验、NaN/零向量拒绝、截取后归一化和冷启动失败。内存不足进入失败/OOM处理，不扩大获批上限。

压力报告记录CPU型号、后端/版本、dtype、模型revision、输入分布、RSS峰值、并发、p50/p95和OOM次数。当前文件没有这些实测值，不把用户指定预设写成已验证性能。
