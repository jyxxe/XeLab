# 卷、临时存储与写入隔离

[文档总目录](../README.md)

> 规格版本：2.6.0；状态：待实现的规范性设计。MUST/必须表示实现及验收要求，不能理解为现有功能。

## 持久卷

createVolume 分配平台管理路径与硬容量配额，用户不能传宿主路径。single_writer 仅允许一个有效实例写入；shared_readonly 允许多个只读挂载，不承诺共享写入。部署级/实例级数据归属通过 VolumeSpec.scope 明确。

底层需启用 XFS project quota 或经同等验收的容量后端。只计算 du、仅限制 I/O 吞吐或只记录清单容量都不算配额生效。底层不支持时卷创建返回存储不可用，不标记 available。

## 挂载

事务中锁定卷，校验 owner/volume 权限、实例代次、mount_path 允许范围和 access 模式；生成单调 volume_fence 后调用运行时挂载。单写锁贯穿迁移和写入实例生命周期，只有确认旧实例退出及卸载完成才能转移。

容器重建挂回原卷。禁用部署、升级和卸载程序不删除卷；删除卷需要独立 volume.delete、If-Match 与 confirm_volume_id 等于路径 ID。卷仍挂载或被恢复操作占用时返回 409。

## 临时盘

容器可写临时区、tmpfs、工作目录和 stdout 日志分别设限。tmpfs 记入内存与临时预算，日志需要单独轮转上限，避免业务卷未满而宿主日志盘耗尽。

扩容仅允许新容量大于当前容量且宿主预算足够；本版无在线缩容接口。接近满额可告警，真正写满由内核/文件系统返回错误；平台记录 volume_full，不对非幂等写入盲目重放。

## Blob

Blob 为不可变受控对象，最多 64 MiB，默认保留 24h；上传先校验长度/摘要再原子发布元数据。未完成上传不出现在列表或下载接口。任务检查点 Blob 在被任务引用期间 pin，不能被 TTL GC 删除。
